# Evolutionary-Differences-in-Navigation-Strategy-Between-Mice-and-Humans
Supplementary materials for the paper Evolutionary Differences in Navigation Strategy Between Mice and Humans Challenge Translational Neuroscience

# Repository README

This repository contains the data, code, and materials associated with the article:

**“Evolutionary Differences in Navigation Strategy Between Mice and Humans Challenge Translational Neuroscience”**  
Loushy Kay, Been, Bikovski, and Pick (2026)

---

## Repository Structure

The repository is organized into three main folders:

### 1. Virtual Reality (VR) T-maze Task
This folder contains the virtual reality (VR) T-maze task and accompanying materials, including:

- **ReadMe T-maze** – Designated ReadMe file with instructions for installing and using the VR T-maze task.
- **License** – License information.
- **T-T-Maze-2023.09.03_-_Eye_Tracking_Fix** – APK file.
- **T-maze test Code** – Compressed folder containing the code and materials.
- **TAUXR Unity Toolkit** – TAU reference file for using the Unity system.

### 2. Supplementary Information
This folder contains:

- **Supplementary Information** – PDF file containing the article’s supplementary information.
- **Supplementary Video 1** – Supplementary video accompanying the article.

### 3. Data files and R code for statistical analysis
This folder contains the datasets, R scripts, and software/package information used for the statistical analyses reported in the article.

#### R analysis scripts:
- **T-maze Mice Comparison 4** – R code for the mouse strain comparison analysis.
- **T-maze Analysis 31 7 Reproducibility** – R code for the main confirmatory cross-species analyses. Fixed random seeds are used to allow reproduction of analyses involving stochastic components, including PERMANOVA on CLR-transformed strategy probabilities and surrogate residuals for the ordinal consistency model.
- **T-maze Analysis Sensitivity 2** – R code for the sensitivity analysis examining the effect of mouse strain.
- **T-maze Human Analysis 4** – R code for the analysis of the human data.

#### Data sets files:
- **Data 2.11.25 wide format** – Dataset used for the analyses.
- **Data 2.11.25 wide format S Variables explained** – Description of all variables in the dataset.

#### Additional:
- **Software and packages** – Information on the software and R packages used for the analyses.
